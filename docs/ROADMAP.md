# Roadmap from a working core to stronger evidence

## Published core

The main publication now answers the worker-protection question through 50 actual long-form replies, their full-text reviews and ten Jev context panels. Its first page separates warning-sign recognition, useful protective steps and implementation of unresolved arrangements. The completed 125-candidate reference-bank pilot adds varied length/register controls and both-order comparisons. The technical companion preserves the broader diagnostics.

The offline CLI validates and scores 937 released decision tasks. The saved Jev responses reproduce the published aggregate exactly. The comparison fixture contains 1,728 requests with equivalent-assessment and changed-conclusion controls. The README and PDF report the evidence in a dated snapshot. Ongoing jobs contribute to later releases.

The decision suite includes arithmetic, explicit action boundaries, evidence sufficiency, role choices and candidate rankings. At the declared 0.5 threshold, Jev accepted all 13 arithmetic claims, including seven deliberately false claims. It correctly handled 576 of 576 explicit action-boundary tasks in that suite. Each family needs replication on varied source cases before we can estimate performance on a broader population.

## Next experiments

Release rc.3 provides reproducible numeric evidence for 27,908 source-case assessments and both completed style-control studies. The immediate priority is to distinguish question-scope changes from unwanted sensitivity. That requires semantic review of the propositions alongside repeated measurements.

## Retained full scope

The live agentic arm will evaluate multi-turn retrieval and authorized tool actions using observable evidence and action traces. Existing fixed conversation histories provide controlled sequential tests; autonomous workflows need their own execution and scoring. Migrasia case-report and evidence-binder integration, multilingual assessment and recurring model-version comparisons remain part of the program. Each completed study can support a release with its own stated scope.

Worker/domain, legal and native-language review are separate validation milestones. Automated experiments continue alongside efforts to obtain those reviews. Reports identify the evidence supporting each claim and the further validation it needs.

## Broader evidence milestones

The original-case track uses 105 advanced/general and 40 referral-specific probes with exact source context. Document-order information views represent progressively available text; historical chronology requires dated source evidence. The [observed-results gallery](ORIGINAL_CASES_AND_OBSERVED_RESULTS.md) includes the first reviewed source examples and their recorded Jev outputs.

We assess coverage, repeated-answer stability, sensitivity and ranking consistency as evidence accumulates. Stopping rules and analysis units belong in the study protocol. Different questions and information states can legitimately produce different answers.

| Priority | Improvement | Required evidence before claiming success |
|---|---|---|
| 1 | Replicate arithmetic and test calibration | Predeclare balanced claims, varied numbers, question polarity and context layouts. Separate ranking from decision thresholds. Fit calibration only on a distinct development set, then test held-out cases. |
| 2 | Complete matched cross-model comparisons | Run the same fixed tasks under declared interfaces; report full coverage and compare matched intersections. |
| 3 | Assess the larger answer arrays | Finish the 20,080-candidate run and 4,320-candidate supplement. Measure requested-versus-assessed tier, refusal, distinctness, length and format adherence. |
| 4 | Validate the judges | Use corrected mixed style controls, swapped positions and multiple model families. Exclude earlier label-cued diagnostics from validity claims. Obtain independent human judgments. |
| 5 | Test improvement over time | Fix a held-out suite, record served versions and decoding settings, repeat on later versions and use paired, group-based comparisons. These measurements will support improvement or regression claims. |
| 6 | Review domain validity | Independent legal/domain adjudication, affected-worker input and native-language review. Explicitly distinguish a concern from a legal finding. |
| 7 | Deploy a protected full-text workflow | Approve recipients and key management, audit evaluators and journals, test OS/process controls and preserve exact texts. The current helper supplies authenticated encryption; runtime isolation and provider retention need separate controls. |
| 8 | Finalize rights and publication packaging | Select a licence, review third-party source rights, extend the reproducibility package and publish a versioned report when evidence changes. |

## Release discipline

Give changes to task text, formatting, evidence, scoring rules or labels a new identifier and transformation record. Preserve failed and missing outcomes. Identify original research questions, adapted scenarios and controlled tasks by their provenance, and derive published results from recorded observations. Worker contact and deployment each require a separately authorized protocol and the stated review.
